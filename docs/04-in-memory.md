# InMemory Queue

`InMemoryDriver` — простая FIFO-очередь на базе `SplQueue`. Подходит для тестов, локальных задач и примеров.

Особенности:
- порядок обработки FIFO
- хранение только в памяти процесса
- метод `size()` для мониторинга длины очереди
- `pop()` увеличивает `attempts` выданной задачи (номер текущей попытки), как `reserve()` у `DatabaseDriver`
- резервирования нет: задача, взятая упавшим процессом, теряется вместе с памятью процесса
